# 三态提案模板（一页，10 分钟填完）

> 宪法（总纲 §4）：新实体必须填满 **白天 Cause → 黄昏 Build → 夜战 Payoff** 三态，任一格填不出或需要新界面 = 假系统，**砍掉进储备库**。复核结果见 `TRI_STATE_REVIEW_4_1.md`。

| 项 | 填写（每格一句话） |
|---|---|
| 名称 / id | |
| 一句话 | 玩家为什么想要它？ |
| **白天 Cause** | 白天玩家**做什么动作**、得到什么？（「无」= 不通过） |
| **黄昏 Build** | 30 秒锁定时**插进哪个槽 / 做什么选择**？（「自动生效」= 不通过） |
| **夜战 Payoff** | 夜里**看得见、听得见**的回报是什么？（只在黎明结算 = 不通过） |
| 复用界面 | 只能选：白天场景交互 / 黄昏插槽面板 / 夜战 HUD / 黎明结算·三选一 / 信件卡 |
| 超休闲版 | 夜战兑现 + 局间合成可用吗？（可选） |
| data.js 字段 | 新表名与 3 个关键字段 + 默认值 |
| 成本 | 新美术 / 新代码量（S / M / L） |
| 结论 | KEEP / REVISE（写改什么）/ CUT（写卡在哪一列） |

**判定**：三格都有「玩家动作或选择」→ KEEP；某格只是「由别的东西兑现」或空 → REVISE 补上，补不上 → CUT。
