# 篝火炖锅：收益与代价表（v1）
> 新建。来源：§4.1、§5.7、§5.8、§5.9；critMul 读 `RW.TUNE.player.critMul`。数值表：`STEW_POT.csv`。

**范围**：6 道菜的材料、增益、代价，材料掉率，锅容量。
**验收**：①每道菜只管一夜，净战力在 **+8%～+20%**（一道菜 < 守卫合一阶的 1/5，守卫合一阶 ≈ +110%，§5.9：盾卫生命 200→420）②每道菜都有真实代价，不存在纯增益 ③菜不花金币（不和召唤抢金币，经济自洽）④材料按首夜击杀量推得出：首夜能做 1 道。

## 关键公式
- 净战力 = (1+输出增益)×(1+生存增益) − 1，其中生存增益 = 1/(1+受伤增加) 或生命倍率；移速 −20% 折算为近战出手率 −10%（ASSUMPTION）。
- 超载菜：期望倍率 = (1−u)×(1+平时) + u×超载倍率，u = 8 s × 2.5 次 / 180 s ≈ 0.11（取自 M0 预期）。
- 材料：首夜 ≈222 杀 → 墨屑 ≈22、余烬 ≈11、狼骑肉 ≈8。墨影冻和狼骑辣肉首夜可做，骨汤要等 Boss 夜。

## 主要调整
骨汤 +40%→+30%（原来 +26% 超预算）；辣肉暴击 15→25%（原来只有 +4.5%）；药粥 2%/s→1%/s（原来一夜能回 360%）；烤薯 ×2/−15%→×2.5/−10%（原来净值为负），配神器初火之冠（超载时长 +50%）可达 +17%，是一条构筑线。

## ASSUMPTION
A1 超载平均每夜 2.5 次（M0 预期，未实测）。A2 移速折算系数 0.5。A3 墨影冻的团队效率 +20% 是估算。A4 焦糖蝠翼的代价（次日伙伴不干活）按经济侧损失计，不折算进战力。A5 掉率都是新设计。A6 暴击对守卫同样 ×2。
