## 圣火 → 桥头（≤ 4 s）
```
路径 (22,14)→(14,14) 沿第 14 列直走 = 8 格（BFS 最短）
d = 8 × 40 = 320 px；t = 320 / 165 = 1.94 s；加速修正 +0.04 s（accel 2300，DATA L22）
t ≈ 1.98 s ≤ 4 s ✅
桥心 10 格 = 2.42 s；北岸桥口 12 格 = 2.91 s；上限 165×4 = 660 px = 16.5 格
```

## 验收
1. 38 行×28 字符，只有上面 ★ 行不同；所有 S 与 C 连通（已脚本检查）。
2. 圣火到南桥头 ≤ 4 s（1.98 s）。
3. 首杀 ≤ 5 s（B §8 M0 #1）：S3 第 0 s 刷小鬼，预警 0.8 + 走到桥口 2.7 ≈ 3.5 s 进入挥砍范围。
