## 命名决定

| 占位名 | 决定 | 理由（一行） |
|---|---|---|
| 司火（第 4 守卫） | 改 **炉卫**（id `brazier`） | 避开「圣火 / 守火人 / 司火」三个火字混淆；与「盾卫」同为「器物 + 卫」，火盆剪影好认 |
| 烬橙 | CONFIRM | 「意象 + 色」格式，读得懂，无冲突 |
| 霜青 | CONFIRM | 「霜」消解青的蓝绿歧义，对应减速 |
| 翠绿 | 改 **藤翠** | 「翠绿」是普通颜色词，改为意象 + 色并呼应藤缚 |
| 皓白 | 改 **晨白** | 呼应黎明主题与「净化回圣火」，格式统一 |
| 星辉（淡紫蓝） | 改 **雷紫** | 「星」与现有「星火圣火」形态撞名，且缺色字；雷对应破甲 |
| 山背石犀 | CONFIRM | 与「崩山巨像」共用「山」，原形关系一眼可见，无已知商标 |
| 月翼蛾后 | 改 **月翼白蝠** | 巨型蛾后易联想知名怪兽 IP；保留蝠母血统，「白」对比墨色夜形 |
