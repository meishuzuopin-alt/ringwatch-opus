## 2. 巡火信使来信样例（黎明三选一，NEED_RUNTIME）
**盲盒**：「守火人，路上捡到个会发烫的小匣子，没敢拆，交给你。里面也许是焰晶，也许是一张旧配方。——巡火信使」
**神器线索**：「北边雾林里，我看见三块会发光的碎片。老人说拼起来叫『初火之冠』，能让圣火烧得更久。两三天能找齐，去不去？」
**寄养传说兽**：「这只小家伙托你照看两天，每天喂一道热菜就行。第三夜它要看你守不守得住火——圣火撑过一半，它就愿意留下。」

## 3. 超休闲 CPI 脚本（竖屏、无字幕依赖；前 3 秒必出挥砍碎裂或护火）
素材规则：只用实机录屏或原创动画；M0 核心（挥砍、碎裂、连击、超载）在 2026-10-17 前仍是目标画面，**未实机前一律标 NEED_RUNTIME，不得投放**。
1. **一刀清屏（15s）** 0–3s 墨色敌群冲上桥，一刀弧光全碎成墨屑。3–10s 连击数上涨，碎屑越来越多。10–15s 结算金光，定格「再来一局」。
2. **火要灭了（20s）** 0–3s 圣火只剩一点火星，手指拖动守火人挡在火前。3–15s 左右拖动拦截，火一点点变旺。15–20s 火光外扩一圈，黎明。
3. **合成变强（20s）** 0–3s 挥砍碎裂开场。3–12s 两个同级守卫拖到一起合成升阶，攻击更猛。12–20s 升阶守卫守住桥口。（合成：NEED_RUNTIME 直到超休闲包实装）
4. **圣火超载（25s）** 0–3s 挥砍碎裂。3–15s 连击冲到 50。15–25s 圣火超载：冲击波、塔射速翻倍、满屏碎裂。（NEED_RUNTIME）
5. **差一点（30s，失败诱导）** 0–3s 护火：黑影扑向火苗，险险挡下。3–20s 敌人越来越多，火光渐暗。20–25s 火熄灭，画面变冷。25–30s 回放同一关，这次守住。（激励视频复活仅超休闲版有，NEED_RUNTIME）
