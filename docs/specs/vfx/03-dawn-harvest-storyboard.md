# 03 黎明收获仪式特效分镜（总纲 §5.6：约 10s 可跳过；战利品飞回圣火 → 圣火 +1 级 → 光圈外扩一环 → 镜头按平方根拉远 → 新地形墨影褪色；之后遗物三选一 / 信使来信）
> 属 Steam 版（M2 起），M0 只有结算面板；此处先定规格。性能数字待实测。

## 色值表
| 用途 | 色值 | 说明 |
|---|---|---|
| 奖励金 | #FFD76A（金币）/ #C18A45（黄铜） | 本段**允许**：金币、飞回的战利品轨迹 |
| 焰晶/残骸 | 焰晶按五色（美术另定），残骸 #3A2F4F | 非金，不与奖励金混淆 |
| 圣火金 / 余烬橙 | #FFB547 / #E8702A | 圣火升级脉冲、光圈边缘 |
| 晨光 | 天空 #1E2A4A → #F2C9A0 渐变 | 环境，非奖励 |
| 危险红 | #FF3B3B | 本段**不出现**（夜已结束，敌人已清） |

## 时间轴（可跳过）
| 段 | 时间 | 画面/粒子 | 镜头 | 后处理 | 音频接点 |
|---|---|---|---|---|---|
| 1 夜转晨 | 0–1.5s | 残余墨影敌人化为墨屑（走 01 碎裂，不给数字）；天空/雾色 1.5s 插值夜→晨 | 静止 | 夜雾浓度 → 0 | `mus_dawn_start` |
| 2 战利品飞回 | 1.5–4.0s | 地上金币/焰晶/残骸依次以抛物线飞向圣火，每件间隔 0.03s；落入时圣火小闪 + 音高逐件升高；>40 件合并成堆（每堆代表 N 件，显示「×N」） | 缓慢跟圣火 | — | `sfx_loot_pickup` 音高递增，同时发声 ≤6 |
| 3 圣火升级 | 4.0–5.5s | 圣火核心亮度 ×2.5 脉冲 0.3s；等级数字（HUD 火光条）+1 回弹；一圈余烬向上喷（≤30 粒） | 推近 4% 后回 | 泛光仅圣火（阈值不变） | `sfx_fire_levelup` |
| 4 光圈外扩 | 5.5–7.5s | 光圈边缘（余烬橙细环 6px）从旧半径扩到 `RW.SANCTUARY` 新半径，ease-out 2s | 按新半径平方根比例拉远，与外扩同步 | 圈内暖光 uniform 半径同步 | `sfx_ring_expand` |
| 5 夺回土地 | 7.5–9.5s | 新环内地块：冷靛剪影→本色（按离圣火距离的扫描线，0.8s 扫完）；墨影粒子向外逃散（≤40 粒） | 静止 | 局部去饱和 → 0 | `sfx_land_reclaim` |
| 6 交接 | 9.5–10s | 落定，弹出遗物三选一 / 信使信件卡（UI 层） | — | — | `mus_day_theme` |
| 跳过 | 任意时刻 | 0.3s 交叉淡入最终状态（金币已入账、半径已扩、地形已着色） | 直接到终态 | — | 所有音效截止，播 `sfx_fire_levelup` 一次 |

## 验收
| 项 | 标准 |
|---|---|
| 时长 | 不跳过 9.5–10.5s；跳过后 ≤0.5s 到终态 |
| 粒子 | 同时 ≤200（含战利品飞行物），特效 ≤2ms（待实测） |
| 颜色 | 金色只出现在金币/战利品；全段无 #FF3B3B |
| 可读 | 静音观看，5 人中 ≥4 人能说出「火升级了、地盘变大了」 |
