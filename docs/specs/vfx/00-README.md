## 开放问题（需策划/美术拍板）
1. 圣火金 #FFB547 算不算「金色」？本规格假定：奖励金 = 金币色 #FFD76A；圣火金只给圣火和英雄。
2. 顿帧是否按 ms 定义？60ms 在 60fps 下取 4f（66.7ms），手机 30fps 下取 2f。
3. 超载起爆顿帧是否可以不计入每秒 200ms 上限？
4. `T.MAX_ENEMIES`=120，低于 M0 验收要求的 150 同屏。
5. M0 没有暴击来源，暴击样式先按遗物/菜预留。
6. 冲击波是否同时击退？
7. 翻盘爆发（伤害 +50%）要不要单独的视觉？本规格没做，建议只在 HUD 上标一下。
8. 伤害数字色值（暖橙 #FF9A4A）需要美术确认，不能和焰晶「烬橙」撞色。
