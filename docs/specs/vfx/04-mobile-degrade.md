# 04 移动端简化清单（超休闲竖屏 420×760，Capacitor；中端安卓特效 ≤1ms/帧，整机 p95 ≤33ms 即约 30fps）
> 以 01 的桌面预算（≈1.75ms）为起点。节省量均为估算，**待实测**。顿帧按 ms 定义，30fps 下 60ms=2f、100ms=3f。

## 降级顺序（自动档按帧时间逐级下降；手机默认从 L2 起步）
| 级 | 砍什么 | 估算省 | 累计特效开销 |
|---|---|---|---|
| L0 | 桌面全量 | — | ≈1.75ms |
| L1 | 余烬：去掉加色光晕，粒数 1–3 → 1；超载边缘余烬 24 → 0 | 0.15ms | 1.60 |
| L2 | FX 泛光关（沿用现有「泛光 → AO → 描边 → 阴影」梯度的第一步）；超载边框改静态半透明 | 0.30ms | 1.30 |
| L3 | 墨屑 6–10 → 3–4 片，池 320 → 128；寿命 0.6 → 0.45s | 0.15ms | 1.15 |
| L4 | 挥砍弧 12/16 段 → 6/8 段，寿命 −20%；塔弹道拖尾关 | 0.10ms | 1.05 |
| L5 | 伤害数字只显示重击与受伤（设置项 `nums`=1），上限 40 → 16，关弹出缩放只保留上浮 | 0.10ms | 0.95 ✅ |
| L6（兜底） | 屏外/远处（离英雄 >400px）特效不生成；屏震 → 0 | 0.05ms | 0.90 |

## 绝不能砍（可读性底线）
| 项 | 理由 | 成本 |
|---|---|---|
| 命中闪白 `iFlash` | 命中确认 | ≈0（实例属性） |
| 顿帧（含每秒 200ms 上限） | 手感核心，总纲 §8 M0#3 | 0 |
| 击杀至少 2 片墨屑 | 「敌人碎裂」是 CPI 钩子（总纲 §8 M1#6） | 极低 |
| 危险预警：敌脚红圈、冲锋线、来袭红箭头、圣火受击闪 | 死亡不委屈 | 必保 |
| 超载起爆细环 + 倒计时环 | 让玩家知道超载发生/结束 | 起爆瞬时 ≤0.1ms |
| 英雄脚下光环 | 人多时找到自己 | 必保 |
