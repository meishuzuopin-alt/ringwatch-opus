# 01 打击感规格（M0 · 总纲 §5.1 / §8 M0#2#3）
> 引擎：Three.js（`js/gl3d.js`）+ 固定步长 `T.DT=1/60`（`js/sim.js`）。所有数字为设计目标，**性能数字待实测**。顿帧以 ms 定义，按帧率换算（60fps / 手机 30fps）。
> 复用现有实现：粒子池 `parts(520)`、数字池 `nums(80)`、特效池 `fx(72)`、FX 实例批 `GL.fxAdd(3000)/fxAlpha(2000)`（2 个 draw call）、立牌实例属性 `iFlash`、顿帧 `G.stop()`+`T.hitstop.gap`、设置项 `shake/flash/fx/nums`。

## 2. 时序（60fps，F0 = 判定命中帧）
| 帧 | 普通 | 重击 / 击杀 |
|---|---|---|
| F0 | 判定→闪白=1→弧出现→数字生成（顿帧开始，sim 冻结，渲染照常） | 同左 + 屏震开始 |
| F1–F3 | 顿帧中：闪白保持，弧/数字动画继续走（渲染时钟不冻） | 同左 |
| F4 | 顿帧结束→击退位移开始→闪白开始衰减 | 顿帧中 |
| F6 | 闪白=0 | 顿帧结束→击退 ×2→碎裂（墨屑+余烬）生成 |
| F7 | 弧消失 | — |
| F10 | — | 弧消失；闪白=0 |
| F36–F42 | 数字淡出结束 | 墨屑/余烬消散（F6+36） |
注：击杀碎裂在**顿帧结束帧**生成，保证碎片沿击退方向飞出。

## 3. 性能预算（150 敌同屏，特效 ≤2ms/帧，**待实测**）
| 系统 | 并发上限 | 池 | draw call | CPU 预算 | GPU 预算 |
|---|---|---|---|---|---|
| 挥砍弧 | 3 条 | 4 | 合进 fxAdd（0 新增） | 0.02ms | 0.15ms（最大填充） |
| 闪白 | 150 | 走敌人实例属性 `iFlash` | 0 | 0.02ms | 0 |
| 墨屑 | 320 | 320（新增，从 parts 拆出） | fxAlpha | 0.20ms | 0.35ms |
| 余烬 | 96 | 96 | fxAdd | 0.05ms | 0.10ms |
| 超载冲击环/边框 | 2 | 4 | fxAdd | 0.01ms | 0.30ms |
| 伤害数字 | 40 | 48 | 1（字形图集实例，或 2D HUD 层 40 次 fillText） | 0.25ms | 0.10ms |
| 实例上传 | — | 只传活跃段 | — | 0.20ms | — |
| **合计** | | | **FX 共 ≤3 个 draw call** | ≈0.75ms | ≈1.0ms → **≤2ms** |
超限裁剪优先级（先砍）：①余烬 ②墨屑片数减半（最少 2 片）③普通数字（保留重击/受伤）④屏外特效（`W3.inView` 剔除，本就应做）⑤弧段数 16→8。**永不裁**：闪白、顿帧、危险预警、圣火受击反馈。
注意：`T.MAX_ENEMIES` 现为 120，M0 验收要求 150 同屏，需数值/工程上调。

## 4. 验收（实测方法）
| 项 | 做法 | 通过线 |
|---|---|---|
| 测试场景 | 建议新增 `?fxbench`：北桥固定 150 敌、英雄自动挥砍、每 10s 强制超载一次、跑 60s | — |
