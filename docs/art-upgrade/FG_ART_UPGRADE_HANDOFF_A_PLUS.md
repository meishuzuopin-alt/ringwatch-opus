## 给 Claude（按顺序做，每阶段一个 `claude/*` 分支或 PR）

### 阶段 0：规则与地基
1. 修改 `AGENTS.md` 硬规则第 1 条，加一个例外：允许引入 **一款 OFL 授权的中文字体**（建议思源宋体 / Noto Serif SC 做标题，思源黑体 / Noto Sans SC 做正文，可以只选一个家族）。在 `docs/ART.md` 里记录字体名、版本、来源和授权，许可证文件一起放进仓库。
2. 字体要**按实际用到的字做子集化**（写一个 `tools/` 脚本，从 `js/` 里的中文文案收集字符，生成子集），控制包体。改了文案以后重跑子集脚本，并把这一步加进 `npm run check`，防止出现缺字。
3. 顺手修掉 Windows 真机验收（GROK-FG-001）发现的问题：
   - 启动约 50 秒才出窗口（连测 3 次都是 50 到 51 秒，卡在 Electron 启动阶段：浏览器进程卡 23 秒，枚举显示器卡 13 秒，日志里有 `WSALookupServiceBegin failed with: 10108`）。原因没确认，请自己排查。
   - 窗口标题被网页标题盖成了「圣火守护者 · 浏览器预览」。
   - 第一次启动时窗口没抢到前台。
   - three.js 警告 `PCFSoftShadowMap has been removed`。
   - exe 用的是 Electron 默认图标（图标也用代码生成），`package.json` 缺 `author`。

### 阶段 1：渲染和光照（观感提升最大）
按圣经第 4、5 节：
- 卡通三段色阶着色、顶点色渐变（下暗上亮）、冷色边缘光、程序噪声斑驳（石、木、茅草）。
- 所有单位和建筑加反向外壳描边：角色 2 像素，建筑 1.5 像素，颜色用本色压暗，不用纯黑。
- 加环境光遮蔽（SAO 或同类做法），让建筑和单位落地。
- 泛光改成**只让圣火、法术和敌人眼睛发光**，关掉现在的全屏泛光（这是画面发白的主因）。
- ACES 色调映射、轻微暗角、夜晚低矮冷雾（远处敌人先露红眼、再显身形）。
- 夜晚环境亮度约为白天的 35%，圣火的暖光圈半径要明确。
- 帧率预算：`npm run audit:game` 的指标不能比升级前明显变差，把升级前后的数字都写进 `docs/AUDIT.md`。给「画质」设置里的低档保留一条关掉 AO 和描边的退路。

### 阶段 3：UI 全套重做（阶段 2 由 Codex 做，两边可以并行）
按圣经第 6 节：
- 深木框加金色描边、四角带小装饰的九宫格边框，用 SVG 或 Canvas 在代码里画，替换所有默认圆角矩形。图标统一线宽、金色描边剪影，也用代码画。
- 标题页：Logo 放上三分之一，菜单改成木框竖排放在左侧（参考 `FG_CONCEPT_01`）。
- 对局 HUD 分三层：
  1. 常驻层：左上是火焰形状的圣火值条，下面是英雄血条和法力条；右上是波次和倒计时；底部中间是建造栏，右下是技能栏。
  2. 情境层：选中单位时在右下弹出信息卡。
  3. 提示层：教程和提示放在顶部中间的横幅或右侧卷轴。**任何提示都不能盖住画面中央 50% 的区域**，请把这条规则加进 `npm run audit:ui`，让它自动检查。
- 敌人来袭预警改成画面边缘的红色箭头。
- 17 个界面全部过 `npm run audit:ui`：文字出屏、按钮装不下、文字重叠都得是 0。文案有改动的地方交给 GPT（`gpt/*` 分支）。

## 给 Codex（阶段 2：调色板和模型造型，改 `world3d.js` 的 `PAL`、昼夜预设和造型函数，`codex/*` 分支）
按圣经第 2、3 节：
- **调色板**：圣火金 `#FFB547`、余烬橙 `#E8702A`（只给圣火和英雄）；暖土 `#C9A27A`、草地 `#6F9A4E`、屋顶赭红 `#A8483A`、木色 `#7A5234`；夜蓝 `#1E2A4A`、月青 `#5FA8C8`、敌紫 `#6B3FA0`、敌眼红 `#FF3B3B`（只用在敌人眼睛和攻击预警上）。白天阴影偏冷蓝紫，不用纯黑或纯灰。同一画面里高饱和色不超过 3 块。
- **英雄**：960×540 下身高不少于 48 像素（大约是现在的 2.5 倍），头身比 1:2；大帽子或头盔、披风、夸张武器三件里至少有两件；脚下一圈暖色光环。
- **敌人**：分三种体型，杂兵小而圆（英雄的 0.6 倍）、精英高而带尖刺（1.1 倍）、重甲宽而矮重（1.4 倍）。身体一律冷紫色，配红眼。
- **建筑**：做成蘑菇式剪影，屋顶夸张、墙比屋顶窄；有梁柱、窗框、烟囱、瓦片层和倒角，不再是一个方块加一个楔形。
- **塔**：靠顶部造型区分，弓塔是尖顶瞭望台，法塔是悬浮水晶，炮塔是粗短炮口。
- **树**：改成多簇叶团，不再是单颗多面球。
- 验收：把画面缩到 231×87 并转成纯黑剪影，英雄、圣火、塔、敌人四类仍然分得清。
- 把圣经要点写进 `docs/ART.md`。需要渲染器新能力的，列进「待工程实现」交给 Claude。
