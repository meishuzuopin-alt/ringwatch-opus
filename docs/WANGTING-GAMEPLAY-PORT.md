# 王庭玩法移植映射

## 版本边界

本轮核对的来源是王者庭院可运行主线 v0.4.1（2D 冒险版本）。旧版疆域循环、三维实验分支和总设计稿中的远期系统不当作已上线功能。这里只实现能服务 Ringwatch 守火玩法的机制，并重新设计数值和表达。

## 已落到 Ringwatch 的玩法

| 王庭侧体验 | Ringwatch 映射 | 当前落点 |
|---|---|---|
| 征战、探索与逐步升级的冒险 | 多波守火远征、精英与 Boss 波 | 既有核心战斗循环；新增守夜印记结算 |
| 伙伴与队伍协作 | 可选英雄、兵营士兵、灯塔防线增益 | 既有十位英雄；新增兵营出兵与引火灯塔协同 |
| 装备、战利品和构筑 | 六种武器、四种主动技能、34 件改造装备和波间商店 | 统一配专属 UI 图标并在购买卡、装备栏和结算构成中显示 |
| 家园经营与成长 | 守护庭院永久祝福 | 余烬印记可升级圣火上限、开局补给、建造折扣和塔伤 |
| 守城与设施协同 | 八种有不同职能的防御建筑及各自科技 | 点杀、减速、吸金、出兵、范围爆破、修复、缚灵和攻速增益 |

## Ringwatch 新增防线职能

- **熔岩炮**：慢速直射爆破弹，适合处理密集敌群。
- **守誓碑**：优先修复射程内受损圣火，否则修复最受损的友方建筑。
- **缚灵柱**：脉冲伤害并强力减速范围内敌人。
- **引火灯塔**：周期增益射程内的建筑，提高攻击和出兵速度。

四种新塔与箭塔、寒霜塔、聚金桩、兵营共同受建造上限、科技升级、商店、敌方拆塔逻辑和 3D 模型渲染管理。

## 长期成长闭环

每局至少获得 1 枚余烬印记，波数与击杀可提高奖励。印记在庭院花费，每项最高五阶；升阶效果从下一局生效。记录保存在现有用户存档中，不依赖在线服务。

## 暂不照搬的部分

王庭的地图探索、剧情关系、孵化和城镇生产属于不同类型游戏的长线系统，无法直接嵌入每局数分钟的 Ringwatch 守塔结构。本次用英雄选择、塔兵协作、波间商店和庭院成长承接队伍、装备、家园成长与防线管理体验；不会把未核实的远期设计宣称为可运行玩法。
