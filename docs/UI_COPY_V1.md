# 阶段 3 UI 文案表 v1

> 状态：文案定稿，供阶段 3 UI 实现直接取用。画面结构与区域以 `FG_ART_BIBLE_001.md` 第 6 节为准。
>
> 语气：**夜里唯一的暖光**。像一本简短、温暖的木偶童话；先说玩家眼前发生的事，再说动作。不用网络梗，不用责备玩家。

## 1. 统一规则

- 按钮主文案 2–4 字；代价、对象和后果放副文案，不塞进按钮名。
- HUD 标签不超过 4 字；教程、警示与飘条不超过 18 个汉字。
- 数字与单位之间留半角空格；波次统一写作「第 {wave} 波」，倒计时统一写作「{seconds} 秒」。
- 「圣火」指中央目标；数值标签用「火光」，避免和技能中的火焰混淆。
- 成功用暖意象（点亮、长明、归来），危险只陈述事实（逼近、受击、将熄），不使用「菜」「失败者」等责备语。
- 所有可替换字段均用 `{field}` 标记；实现时不显示花括号。

## 3. 边缘来袭箭头

箭头只显示方向与以下短语；不弹窗、不暂停。

| 等级 | 文案 | 使用条件 |
|---|---|---|
| 普通 | `黑影逼近` | 常规敌群进入预警距离 |
| 快速 | `疾影来袭` | 高速敌人 / 冲锋单位 |
| 精英 | `强敌逼近` | 精英单位 |
| 攻城 | `直扑圣火` | 仇恨目标为圣火 |
| 首领 | `巨影来袭` | Boss / 终局敌人 |
| 多方向 | `四面有敌` | 同时出现 3 个及以上方向 |

色弱辅助模式只改变箭头颜色与纹样，文案不变。

## 4. 页面文案

### 4.1 标题页

- 标题：`圣火守护者`
- 英文副标：`FLAME GUARDIAN`
- 标语：`长夜围住村庄，你是火旁最后的守护者。`
- 主按钮：`开始守护` / 有存档时 `继续守护`
- 次按钮：`新的守护`（副文案：`将放弃上局`）、`每日挑战`、`火光纪录`、`玩法`、`设置`、`退出`
- 无纪录时：`第一簇火，正等你点亮。`
- 存档损坏时：`旧旅程无法读取，可以开始新的守护。`

### 4.2 英雄与本局设置

- 标题：`选择守火人`
- 副文案：`每位守火人，都有自己的火边故事。`
- 区块：`地图`、`危险`、`变异`、`分数倍率`
- 主按钮：`举火出发`
- 锁定：`尚未相遇`（详情：`解锁条件：{condition}`）
- 无英雄可选：`还没有守火人回应召唤。`
- 地图锁定：`这条路尚未点亮。`

### 4.3 波间整备

- 标题：`波间整备`
- 副文案：`天色稍缓，为下一阵脚步声做准备。`
- 分区：`武器`、`技能`、`圣火`、`套装`、`进化`
- 按钮：`购买`、`刷新`、`锁定` / `解锁`、`禁用`、`出售`、`进化`、`护火`、`升级`、`迎战`
- 空货架：`货架空了，刷新看看。`
- 售罄：`这件已经卖完。`
- 满持有：`已经带到上限。`
- 刷新不足：`还差 {amount} 金币。`
- 禁用耗尽：`本局禁用次数已用完。`
- 下一波：`第 {wave} 波 · {enemySummary}`；首领波尾注 `巨影将至`。

### 4.4 设置 / 按键

- 标题：`设置`；子页：`按键设置`
- 按钮：`改键`、`恢复默认`、`切换全屏`、`完成`
- 等待输入：`请按下新按键`；取消：`按 Esc 取消`
- 冲突：`该按键已占用，已互换。`
- 不支持：`这个按键不能使用。`
- 恢复确认：`所有设置将恢复默认。`
- 保存失败：`设置未能保存，请重试。`

### 4.5 暂停

- 标题：`暂停`
- 副文案：`火光在这里等你。`
- 按钮：`继续`、`设置`、`重新守护`、`回到标题`、`结束守护`
- 回标题副文案：`已存至第 {wave} 波前`
- 未存档副文案：`尚未整备，本局不保存`
- 结束副文案：`立即查看结算`

### 4.6 圣火熄灭 / 复活

- 标题：`圣火熄灭`
- 副文案：`余烬还暖，仍可再点一次。`
- 按钮：`重燃圣火`（副文案：`剩 {left}/{total} 次 · 恢复半数火光`）、`查看结算`
- 次数耗尽：`余烬已冷`
- 不可复活：`今夜的守护到此为止。`

### 4.7 结算

- 胜利标题：`圣火长明`
- 失败标题：`守到第 {wave} 波`
- 无尽标题：`长夜第 {wave} 波`
- 新纪录：`新的火光纪录`
- 统计：`击杀`、`金币`、`位阶`、`最高连杀`、`守火时长`、`新成就`
- 按钮：`继续无尽`、`再守一夜`、`重新选择`、`返回标题`
- 无新解锁：`这一夜没有新解锁。`
- 无数据：`这段旅程没有留下纪录。`

### 4.8 火光纪录与成就

- 标题：`火光纪录`
- 页签：`成就`、`最近旅程`
- 汇总：`守护局数`、`通关次数`、`最高分`、`累计击杀`、`累计金币`、`无尽最高`
- 英雄栏：`守火人 · 最高波次 · 最高危险`
- 成就未解锁：`尚未点亮`
- 成就空状态：`第一枚火印，正等你赢得。`
- 最近旅程空状态：`还没有旅程写进火光。`
- 读取失败：`纪录暂时读不到，请稍后重试。`

## 5. 通用按钮、空状态与错误

### 5.1 通用按钮

`确认`、`取消`、`返回`、`关闭`、`重试`、`继续`、`明白`、`稍后`、`查看`、`跳过`。

### 5.2 空状态

| 场景 | 文案 |
|---|---|
| 无存档 | `还没有未完的旅程。` |
| 无商品 | `货架上只剩木屑。` |
| 无成就 | `第一枚火印尚未点亮。` |
| 无纪录 | `火光还没记下故事。` |
| 无搜索结果 | `没有找到相符的故事。` |
| 无可选祝福 | `圣火暂未回应。` |

### 5.3 错误与确认

| 场景 | 标题 | 正文 | 按钮 |
|---|---|---|---|
| 通用错误 | `出了岔子` | `火光晃了一下，请重试。` | `重试` / `返回` |
| 存档失败 | `未能保存` | `旅程还没写下，请再试一次。` | `重试` / `稍后` |
| 存档损坏 | `纪录受损` | `旧旅程无法读取，可开始新的一局。` | `新的守护` / `返回` |
| 放弃存档 | `另起一程？` | `未完的旅程会留在长夜里。` | `确认` / `取消` |
| 重开本局 | `重新守护？` | `今夜的进度将从头开始。` | `重开` / `取消` |
| 退出游戏 | `暂别火光？` | `已保存的旅程不会丢失。` | `退出` / `取消` |
| 断开手柄 | `手柄离开` | `请重新连接，或改用键鼠。` | `明白` |
