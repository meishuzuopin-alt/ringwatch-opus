# 设计储备：「王者庭院」设计稿对照

负责人贴来一份很长的设计稿（原名「王者庭院」）。里面有阿尔卑斯田园、昼夜双相、开罗式经营、门派江湖、动物养成、转生、园长来信、博物馆等内容，其中一部分还是另一套 Godot 工程的讨论。
这里逐条对照《圣火守护者》现状，分成四类：已经有了、下一批能做、要负责人拍板、按项目规则不能照做。
设计稿自己的原则我们也认：先把一个夜晚打爽，再往上叠系统。每一条都要过它提出的「三态表」：白天做什么、开战前怎么布置、战斗里有什么反馈。三列填不满的就不做。

## 一、已经有了（对应设计稿里的说法）

| 设计稿 | 我们的实现 |
|---|---|
| 昼夜双相：白天整备、夜里高压 | 波间整备（商店、祝福、升圣火）加战斗波次；夜晚、Boss 波有独立的光照预设和音乐段 |
| 英雄亲自下场、顿帧、击退、碎块、音阶攀升 | 英雄自己战斗；命中停顿、击退、尸块、连杀音高攀升、战意分档 |
| 塔是「装备载体」 | 武器流派套装、武器进化；塔用科技升级（插槽式改塔见第二类） |
| 失败不挫败 | 英雄倒计时复活，圣火每局 3 次重燃，快速重开，死因提示 |
| 转生：新周目有降维打击的爽感 | 危险等级 0–5、变异器、每日挑战（**不做永久数值成长**，见第三类） |
| 地图开阔、要离家作战 | 56×56 正方形大图，郊野祭坛，王旗 10 站 |
| 生产与守护绑在一起 | 圣域收成：圣火照到的土地和房屋每波产金 |

## 二、下一批能做（不违反规则、工程量可控，按收益排序）

1. **建筑相性（开罗式 COMBO）**：相邻建筑触发加成，例如箭塔挨着寒霜塔会让箭附带减速，兵营挨着聚金桩会让士兵出生带护甲。数值写进 `data.js`，放下时弹出「相性 UP」。
2. **塔的插槽改造**：整备时把一件道具「插」到某座塔上，改变攻击形态，例如战斧型变成近身旋风，弩型变成扇形齐射。复用现有的武器数据。
3. **元素反应**：冰和火同时命中触发「碎裂」范围伤害，雷和水触发连锁。
4. **随机来客事件**（同福客栈式）：整备时偶尔来一位客人，用金币换一次性增益，或者接一个下一波的赌约（例如只靠兵营守一波，奖励翻倍）。纯文字事件加一张原创程序化头像。
5. **园长来信 / 信使**：每 5 波来一封信，三选一：限时借你一个强力同伴、给一张收集任务、或者是一个盲盒。
6. **农田地块**：在圣域里的空地上插旗开田，每波自动收成；敌人踩过会减产。这是圣域收成的延伸。
7. **死因明信片**：结算时生成一句带点幽默的战报（全是原创文案）。
8. **双人同屏合作**：一人主战，一人管建造和兵营。需要把输入拆成两套，工程量中等。

## 三、需要负责人拍板

- **永久成长 / 转生天赋树**：设计稿和 Codex 分支里的「余烬印记」都想加永久数值。白皮书当前的原则是「不做永久数值成长，只解锁内容」，因为很多玩家的差评就是「肝」和「前期被数值卡」。可以做一个折中：只解锁新英雄、新形态、新变异器，不加属性。
- **大地图 4X 层**（文明 6 / 英雄无敌式的迷雾、分城、带兵巡游）：这是另一种游戏的规模，会拖慢上架。建议留到正式版以后，先用「郊野祭坛 + 王旗推进」模拟探索感。
- **门派江湖 + Galgame 好感**：要写大量剧情和立绘；立绘只能是程序化生成的，或者负责人另外同意引入的原创美术。
- **动物养成 / 三合一 / 叠罗汉**：现有的「同伴合成」已经是三合一的雏形，可以把它换成动物外形。需要确定美术方向（交给 Codex）。

## 四、按项目规则不能照做（附替代方案）

| 设计稿 | 问题 | 替代 |
|---|---|---|
| 用 Kenney / Mixamo / Unity 商店资产，或公版名画高清图 | 硬规则 1：模型、音乐、音效全部由代码生成，不引入外部素材文件 | 继续用程序化低模；「博物馆」可以做成程序化画框，配原创纹样 |
| 少林、武当、金庸人物、宋远桥等真实门派名和作品人物 | 硬规则 8：不用仍在版权期内的作品与人物 | 全用原创门派名，例如「青崖剑庐」「铁钟禅院」「霜狼部」 |
| 网络梗人物（「背带」「疯狂星期四」等） | 可能涉及真人形象和商标 | 只保留「会自爆分身的逃跑法师」这类原创机制，不影射具体的人或品牌 |
| 换成 Godot 重写、HD-2D 管线、`gdshader` | 项目的技术栈是 Three.js + Electron（AGENTS.md），换引擎等于推倒重来 | 同样的「吉卜力双色阶阴影 + 边缘光 + 风摆」可以在 `gl3d.js` 的着色器里实现，交给 Codex 写进 `docs/ART.md` 的「待工程实现」 |
| 借用《王国保卫战》源码 | 闭源商业代码 | 只借机制：兵营拦截、索敌优先级这类通用规则。现在的兵营指挥就是自己设计的 |
