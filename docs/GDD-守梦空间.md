## 一句话

博物馆夜班保安带着一只肥猫「缪斯」，沿着艺术史时间线潜入大师们的梦境，守住灵感、打跑由名画变成的荒诞怪物，让名画顺利诞生。
类型：竖屏 · 割草 + 塔防 + 肉鸽 · 荒诞搞笑 · 局外数值养成。

## 故事契机：「大褪色」

- 深夜，馆藏名画的油彩像沙子一样剥落：蒙娜丽莎变成苦瓜脸，星空熄灭成一片死灰。
- 幕后：由千篇一律的流水线内容滋生的「审美虚无」邪灵，逆着时间回到源头，想在大师动笔之前掐灭灵感。
- 主角捡来的流浪猫其实是艺术之神「缪斯」，能咬开时空画轴。主角是唯一听得懂猫叫的人，于是成为「灵感守梦人」。
- 每通一章，现实展馆里对应的名画恢复色彩；最终章结束，整座展馆重新亮起。

## 单局循环（约 10–15 分钟）

1. **铺底色**：场地是线稿，怪零星出现；走位割草、捡颜料、放 1–2 座塔。
2. **上色**：精英怪带「名画词条」进场；三原色混色频繁触发，塔阵成型。场景逐渐被上色。
3. **罩染与高光**：超武觉醒，怪海涌入，小猫大招就绪。
4. **落款**：Boss 降临；最后一击触发慢动作签名，全屏净化，名画上框。

## 系统清单

**局内**
- 主角：画笔 / 画刀自动攻击，走位割草。
- 三原色：掉红黄蓝颜料，混色切换攻击属性（橙 = 爆裂，绿 = 毒地 / 回血，紫 = 聚怪）；敌人有底色，打相克色触发「破色硬直」。
- 防御塔：石膏像加特林、定画液喷雾机（减速 / 石化）、画框陷阱。
- 三选一构筑：印象派（暴击 / 灼烧）、立体主义（弹射 / 穿透）、野兽派（近战 / 移速 / 油彩轨迹）。
- 超武合成：满级技能 + 名作遗物 → 终极技能（如「大水枪」+「干草堆」=《印象·日出光炮》）。
- 小猫「缪斯」：踩奶（修复画板）、扑咬（弹射输出）、打翻水杯（全屏击退）三种模式。
- 随机事件：「甲方要求改稿」（怪物血量 ×2，掉落 ×3）、「艺术家宿醉」、「拍卖行抬价」。
- 负面词条：受潮发霉、颜料龟裂、松节油泄漏。

**局外**
- 货币：局内有 油彩原浆、金箔碎屑；局外有 声望币（天赋树）、金枪鱼罐头（小猫）、灵感结晶（重铸装备）。
- 天赋树「艺术史编年谱」：学院派（塔防）/ 狂热派（割草）/ 超现实派（机制与收益）三条分支。
- 装备：画笔 / 调色盘 / 画架 / 围裙 四个槽位，装备是大师遗物。
- 猫咪画廊：通关的名画以猫咪版本挂在主界面，提供永久加成。

**包装**
- 画板的血量是「画布平整度」，掉血时起皱、撕破；技能冷却是一圈风干的油漆；暂停是「闭馆检修」封条；失败盖「流拍」章。

## 分期建议

- **M1 · 序章可玩（最先做）**：达·芬奇一章完整换皮；小猫只做一种模式；画板、灵感进度条、名画诞生演出；三选一取代商店。**目标：拿去给人试玩，验证题材吸不吸引人。**
- **M2 · 局外养成**：声望币 + 天赋树（每条分支先做 5 个节点）+ 猫咪画廊 + 激励视频接入点。**目标：留存与变现的骨架。**
- **M3 · 第二、三章**：伦勃朗明暗机制、梵高三原色混色。
- **M4 以后**：装备、超武合成、随机事件、更多章节。

## 待决事项

1. **画风**：沿用现在的 3D 低多边形（最快，渲染器刚升级完），还是改 2D？「油画质感、名画上框」这类表现，用 2D 贴图会容易得多。
2. **「画面全部运行时生成」这条规则要不要放宽**：名画题材很依赖画作图像（上框演出、画廊）。达·芬奇、梵高等大师的原作都是公版，可以用；但一用就涉及图片资源、包体大小（主包 4MB）和分包。
3. **版权与人物**：公版可放心用的有达·芬奇、伦勃朗、莫奈、梵高、北斋、蒙克。**达利、毕加索、沃霍尔的作品仍在版权期内**，遗产基金会维权积极；「金宝汤」是注册商标，梦露涉及肖像权。建议这几位改成致敬化处理（比如「融化的钟」这类风格元素，不出现真名和原作），或者上线前请法务确认。拿真实人物的病痛开玩笑（比如梵高的耳朵、精神状况）也要把握分寸。
4. **变现路线**：微信小游戏没有版号时只能做广告变现（激励视频 / 插屏 / Banner）；做内购需要版号。所以「数值养成」前期应该围绕激励视频设计（翻倍奖励、复活、免费刷新），内购等拿到版号再说。以上请以微信官方最新规则为准。
