# 环带值守

奇幻守村 · 低多边形 3D · 法师 / 弩手。画面是自带的轻量 WebGL 渲染器实时生成的，不依赖任何第三方库；设备不支持 WebGL 时会自动退回 2D 画面（浏览器里在地址后加 `?2d` 也能强制 2D）。

## 怎么打开

**微信开发者工具**
1. 打开微信开发者工具，选「小游戏」→「导入项目」。
2. 目录选本文件夹 `ringwatch-opus`。AppID 可以先用测试号（工程里默认是 `touristappid`），上线前换成你自己的。
3. 导入后会自动编译运行。入口是 `game.js`，逻辑分辨率 420×760，竖屏。

**浏览器预览**
在本文件夹里启动任意静态服务器，然后打开 `preview.html`，例如：

```
python -m http.server 8080
# 浏览器访问 http://localhost:8080/preview.html
```

直接双击 `preview.html` 一般也能运行；如果浏览器拦截了本地脚本，就用上面的方式。

## 开发

需要 Node 18+。协作分工与规则见 `AGENTS.md`，美术方向见 `docs/ART.md`。

```
npm install          # 只装测试用的 Playwright，游戏本身零依赖
npm run dev          # 本地预览 http://localhost:8080/
npm run check        # 提交前必跑：语法 / 入口一致 / 模拟冒烟 / 包体
npm run test:flow    # 浏览器流程测试
npm run shots        # 美术评审截图，输出到 shots/art/
npm run balance      # 数值测试
```

每个 PR 会自动跑以上检查，截图在 Actions 运行页面的 `screenshots` 产物里下载。

## 怎么操作

- **移动**：按住屏幕任意位置拖动（浮动摇杆）。电脑上用 WASD 或方向键。
- **攻击**：武器会自动瞄准、自动开火。
- **冲刺**：点右下「冲刺」（电脑上按空格或 Shift）。冲刺中短暂无敌，能撞伤敌人。
- **技能**：点右下的技能圆键（电脑上按 Q 或 E）。
- **造塔**：点左下「造塔」，再选一种建筑，会建在你脚下（电脑上按 B，再按 1–4）。
- **战意**：在身边击杀敌人会攒战意，攒满进入「狂热」，攻速、伤害、移速一起涨；逃跑时战意会掉。
- **职业**：法师离敌人越近伤害越高；弩手站着不动会叠「凝神」，叠满后暴击变高、弩箭能穿透。
- **灵火晋升**：碰到发光的灵火就会吸收，攒够以后晋升位阶；位阶高了，小怪可以直接踩碎。
- **守护圣火**：村子中央的圣火熄灭，这局就结束。敌人从北面山道过桥，也会从东、西、南三个入口进村。圣火不在屏幕里时，屏幕边缘会有箭头指向它。
- **整备**：点卡片右侧的价格按钮购买；「锁定」能把卡留到下一轮；点两次武器槽可以出售；圣火在整备页维修或加固。
- **暂停**：点右上角 ‖（电脑上按 Esc 或 P）。
- **电脑上的其他快捷键**：Enter 开始游戏或进入下一波；整备时按 1–4 购买，按 R 刷新。

## 广告位以后填哪里

打开 `js/data.js`，在文件开头的 `RW.AD` 里填：

```js
RW.AD = {
  REWARD_REVIVE: '',   // 激励视频广告位 ID：复活（第 4 波起）
  REWARD_REROLL: '',   // 激励视频广告位 ID：整备时免费刷新（第 4 波起，每轮一次）
  FIRST_AD_WAVE: 4
};
```

留空时，按钮显示「预览发放」，直接发放奖励，不会播放任何广告。填上广告位 ID 后，按钮变成「看广告」，走 `wx.createRewardedVideoAd`，只有完整看完才发奖励。游戏里没有插屏广告，战斗中也不会弹任何广告。
